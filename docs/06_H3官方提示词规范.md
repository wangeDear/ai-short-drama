# H3 官方 Ref2VA 提示词规范（调研归档）

> 来源: MiniMaxAI/MiniMax-H3 官方仓库 docs/VIDEO_PROMPT_WRITING_GUIDE_ref_en.md
> 抓取: 2026-08-15 (zhipu web-reader)

## 六段式结构（Full-Reference 模式官方要求）

| 段落 | 作用 |
|---|---|
| `subject_definitions` | 用标签定义参考内容: `<SubjectN>`(可复用视觉内容/人物/场景) `<PictureN>`(具体帧锚点) `<ClipN>`(视频结构参考) `<SoundN>`(音频参考/音色) |
| `summary` | 一段话概述 + 方括号任务类型前缀: `[reference generation]` `[keyframe completion]` `[video continuation]` `[audio reference]` 等,多任务用 `+` 连接 |
| `retention_analysis` | 每个参考标签的保留关系: `fully_preserved` / `partially_preserved` / `attribute_transfer` / `weak_reference`; 音频用 `fully_copy` / `partially_copy` / `reference` |
| `detailed_description` | 主体: 风格开头 1-2 句 → `[Shot 1]` 无时间戳 → `[Shot N] At MM:SS.mmm, ...` 切点; 350-500 英文词 |
| `overall_soundscape` | 环境声/物理声(对白不写这里) |
| `non_diegetic_music` | 观众可听 BGM(角色听不到的配乐) |

## 对白格式（关键！）

- 说话人: 全局编号 `(S1)` `(S2)`,按实际发声顺序分配,跨镜头复用
- 格式: `<SubjectN> (S1) says, [Chinese] `中文台词原文。``
- 语言标签: 对白保留原语言,前缀 `[Chinese]` / `[English]` 等
- 音色锁定: `<SoundN> is the voice-timbre reference for <SubjectN> (S1).` + retention 里写 `: reference - its vocal timbre guides the dialogue delivery...`
- 唇动细节要写: "He closes his mouth into an apologetic smile" 等闭嘴/停顿动作
- off-screen 画外音标注 `off-screen`
- 标点规范化: 只用 , . ? ! ; 台词结束必须有句号/问号/叹号

## 与我们 v1 prompt 的差距（对白乱的根因）

| 项 | 我们的做法 | 官方要求 |
|---|---|---|
| 结构 | 自由文本一段流 | 六段式结构化 |
| 参考图 | `<Picture 1> is ...` 简单标签 | subject_definitions 定义 + 各段引用 + retention 分析 |
| 对白 | 英文句子内嵌中文括号说明 | `[Chinese] `台词。`` + speaker ID |
| 说话人 | 未编号 | 全局 (Sx) 编号体系 |
| 唇动 | 未描述 | 说话前后的嘴部动作要写 |
| 声音分层 | 一句 Sound design | soundscape 与 BGM 分离,对白只在 detailed_description |
