## 一、定稿架构（H3 vlog 管线）

```

│ 画面层  MiniMax H3 Ref2VA（逐镜，参考图锁人物场景）              │

└────────────────────────────────────────────────────────────┘
```

## 二、六段式 prompt 模板（对白质量的核心，可直接复用）

```text
subject_definitions:
<Subject1> is {角色描述}, visual identity from <Picture 1>.
<Picture 2> shows the scene location and lighting.

summary: [reference generation] A vertical selfie vlog clip ...

retention_analysis:
<Picture 1>: fully_preserved — face/hair/outfit must match exactly.
<Picture 2>: weak_reference — only setting and daylight.

detailed_description: {风格 1-2 句} + [Shot 1] {画面动作} +
  口型: <Subject1> (S1) says, [Chinese] `中文台词。`  ← 语言标签+反引号+句号
  + 唇动细节(闭嘴/停顿/凑近低语)                       ← 不写会假

overall_soundscape: {环境音/物理音, 对白不写这里}

non_diegetic_music: none.
```

**对白铁律**：台词结尾必须有句号；说话人全局编号 (S1)；说话前后写闭嘴动作；
边做边说=大动作镜头可同步口型（实测可行）。

## 三、工程参数（实测）

| 项 | 值 |
|---|---|
| 模型 | minimax_h3_ref2va_pruned_int8_convrot（20G, 5090 32G 稳定）|
| 文本编码 | qwen3vl_32b_nvfp4_awq |
| 帧对齐 | length % 17 == 5（h3_len 函数）|
| 采样 | res_multistep / simple / 20 步 |
| 时长设计 | 口型镜=台词字数÷4字/s+2s；其余 4-6s |
| seed | 每镜固定 seed（镜 id 派生）|
| 性能 | 单镜 168-377s（544×960）；24 镜全片 ≈1.6h |
| demo 策略 | 新风格先 3 镜 demo（30 分钟）验收后再全量 |

## 四、LTX 备选线的实战结论（为何降级）

| 问题 | 现象 | 结论 |
|---|---|---|
| 写实天花板 | "太假不像真实荒野求生"（用户否决） | LTX 蜡像感/3D 味为模型固有，参数无解 |
| 1080p 黑屏 | int8 distilled @1920×1088 → 12/18 场 NaN 黑帧 | 安全上限 704p；704p+官方latent超分×2 是升级路径 |
| 空音频 NaN | AV 链路 >300 帧 aac Input NaN 崩溃 | 长场必须纯视觉生成+音频外挂 |
| 可取之处 | 速度 3-7 倍于 H3 | 草稿/Animatic 可用 |

## 五、H3 管线踩坑速查

1. 对白含糊 → 根因是 prompt 不合六段式（02 文档调研），v9 实测修正后"基本能对上"
2. 单段 >15s 的多镜头叙事 → 不可达尾帧跑飞；vlog 逐镜模式天然规避
3. 特效镜 AI 感 → prompt 加 "natural-looking jagged bolt / sideways" 等自然化描述
4. ComfyUI API：MiniMaxH3ReferenceToVideo 的 ref_images 列表 + ref_image_size="match"
5. pod 重启可能清 output（overlay 非持久）→ **产物生成即拷回**（血泪：LTX-2.3 全片丢失）
6. compshare：start 无 --yes；stop 有；SSH 后台任务用 `(nohup ... &)`
